# F2 Base — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar lista la app Next.js + Payload de la Guía con todas sus colecciones, permisos, redirecciones automáticas, migraciones, seed, almacenamiento en R2, respaldos y CI (pasos 1–3), sin sitio público todavía.

**Architecture:** Una sola app Next 16 + Payload 3 (plantilla `blank` de `create-payload-app`). La lógica de negocio que no depende de Payload vive en `src/dominio/` (funciones puras, pruebas unitarias). Los permisos viven en `src/acceso/` y las colecciones los importan; ninguna colección define su propio acceso en línea. Las redirecciones automáticas viven en `src/redirecciones/` como fábricas de hooks que las colecciones registran. Todo lo que toca la base se prueba con Vitest contra Postgres real (Docker en local, servicio de GitHub Actions en CI).

**Tech Stack:** Node 24 (≥ 24.22.1), npm, Next.js 16.4.3, Payload 3.92.1 (`@payloadcms/db-postgres`, `@payloadcms/richtext-lexical`, `@payloadcms/storage-s3`, `@payloadcms/plugin-redirects`), Postgres 17, Vitest 4, sharp.

**Spec:** `docs/specs/2026-10-30-guia-baja-design.md` (secciones 4, 5, 6, 11 y fase F2 de la sección 14).

## Global Constraints

- Payload **≥ 3.73** y Next.js **≥ 16.2.6**; este plan fija Payload `3.92.1` y Next `16.4.3` (Payload 3.92.1 exige Next ≥ 16.3.3). Versiones exactas en `package.json`, sin `^`.
- No usar Cache Components / PPR.
- Node.js 24 LTS; Payload 3.92.1 exige Node ≥ 24.22.1.
- Gestor de paquetes: npm.
- `assetPrefix: '/guia-assets'`; archivos de `public/` dentro de `public/guia-assets/`.
- Imágenes sin el optimizador de Next (`images.unoptimized: true`).
- GraphQL de Payload apagado.
- Localización: `es` (por defecto) y `en`, `fallback: false`. Toda consulta pública usa `fallbackLocale: false`.
- Acceso **negado por defecto** en todas las colecciones.
- Slug de la colección de usuarios fijo: `users`.
- Login: bloqueo tras 5 intentos fallidos durante 10 minutos; contraseñas de 12 caracteres o más.
- Fechas en `America/Mazatlan`; un patrocinio cuenta desde las 00:00 de ese huso.
- Slugs en minúsculas ASCII con guiones; slugs reservados de Zonas: `lugares`, `places`, `eventos`, `events`, `articulos`, `articles`, `categoria`, `category`, `aparece-en-la-guia`, `get-listed`, `privacidad`, `privacy`.
- Redirecciones tipo `308`.
- Migraciones con `payload migrate:create`, commiteadas; nunca `push` (el adaptador va con `push: false`). Toda migración compatible con el código anterior (expandir y luego contraer).
- Producción migra con `DATABASE_URL_UNPOOLED`; la app corre con `DATABASE_URL`.
- Nunca datos reales en local, CI ni previews. El seed se niega a correr sin `SEED_PERMITIDO=true`.
- Los logs nunca llevan correo, teléfono ni IP.
- Hooks que revalidan caché respetan `req.context.disableRevalidate` (F2 no revalida nada todavía, pero el seed ya lo pone).
- Identificadores de dominio en español, como en el spec.

## Fuera de este plan (F3/F4)

Publicación programada (`schedulePublish`, configuración de `jobs` y su cron; se agrega con una migración de solo expansión), páginas públicas, `proxy.ts` de la Guía y `origenDePeticion`, formulario y Server Action, Turnstile, Resend, revalidación de caché y crones, anonimización de Solicitudes, aviso de privacidad, analítica, sitemap, JSON-LD, listados/umbrales/orden/`hreflang`, endpoint `/api/publico/v1`, bloque de tours, E2E y Lighthouse.

Regla de hooks: **un hook nunca llama a la Local API pasando el `req` de la operación junto con un `locale` distinto** (la Local API reescribe `req.locale` y Payload descartaría los campos localizados que el editor está guardando). Las lecturas por idioma o con `locale: 'all'` dentro de hooks usan `req.payload.db.findOne` / `req.payload.db.count` con `req`. `registrarRedireccion` usa la Local API con `req` pero sin `locale` (la colección `redirects` no es localizada). Prueba de integración que lo vigila: editar `resumen` en `es` de un Lugar publicado y comprobar que se guardó.

Importaciones dentro de `src/` siempre relativas (no `@/`), para que funcionen igual en Next, en `payload run`, en Vitest y en `globalSetup`.

Reglas de dependencia: `dominio/` no importa nada del proyecto. `acceso/` importa solo `dominio/` y tipos de Payload. `campos/` importa `dominio/` y `acceso/`. `redirecciones/diferencias.ts` importa solo `dominio/`; el resto de `redirecciones/` importa `dominio/` y `acceso/`. `collections/` y `globals/` importan `campos/`, `acceso/`, `redirecciones/hooks.ts`, `bloques/`. `payload.config.ts` importa colecciones, globals, `redirecciones/plugin.ts` y `almacenamiento.ts`. Nada importa `payload.config.ts` salvo las rutas de `app/(payload)`, el seed y las pruebas de integración.

export const SLUGS_RESERVADOS_ZONA = [
  'lugares', 'places', 'eventos', 'events', 'articulos', 'articles', 'categoria', 'category',
  'aparece-en-la-guia', 'get-listed', 'privacidad', 'privacy',
] as const

const FORMATO = /^[a-z0-9]+(?:-[a-z0-9]+)*$/

export function slugify(texto: string): string {
  return texto
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
}

export function esSlugValido(slug: string): boolean {
  return FORMATO.test(slug)
}

export function esSlugReservadoZona(slug: string): boolean {
  return (SLUGS_RESERVADOS_ZONA as readonly string[]).includes(slug)
}

`src/dominio/idioma.ts`:

export const LOCALES = ['es', 'en'] as const
export type Locale = (typeof LOCALES)[number]

function textoDeLexical(nodo: unknown): string {
  if (!nodo || typeof nodo !== 'object') return ''
  const n = nodo as { text?: unknown; children?: unknown; root?: unknown }
  if (n.root) return textoDeLexical(n.root)
  const propio = typeof n.text === 'string' ? n.text : ''
  const hijos = Array.isArray(n.children) ? n.children.map(textoDeLexical).join('') : ''
  return propio + hijos
}

export function tieneValor(v: unknown): boolean {
  if (v === null || v === undefined) return false
  if (typeof v === 'string') return v.trim() !== ''
  if (Array.isArray(v)) return v.length > 0
  if (typeof v === 'object' && 'root' in (v as object)) return textoDeLexical(v).trim() !== ''
  return true
}

// Regla de idioma (spec §6): un documento existe en un idioma solo si todos estos campos tienen valor en él.
export function existeEnIdioma(doc: Record<string, unknown>, campos: readonly string[]): boolean {
  return campos.every((c) => tieneValor(doc[c]))
}

// Para documentos leídos con locale 'all': cada campo localizado llega como { es, en }.
export function aplanarIdioma(
  doc: Record<string, unknown>,
  locale: Locale,
  camposLocalizados: readonly string[],
): Record<string, unknown> {
  const plano: Record<string, unknown> = { ...doc }
  for (const campo of camposLocalizados) {
    const valor = doc[campo]
    plano[campo] =
      valor && typeof valor === 'object' && !Array.isArray(valor)
        ? (valor as Partial<Record<Locale, unknown>>)[locale]
        : undefined
  }
  return plano
}

const DESFASE = '-07:00'

const formatoDia = new Intl.DateTimeFormat('en-CA', {

  month: '2-digit',

})

export function diaEnMazatlan(fecha: Date): string {

export function inicioDelDiaMazatlan(fecha: Date | string): Date {

// Vigente: sube en el orden de los listados (spec §6, §7).

import type { FieldHook, TextField } from 'payload'

import { esSlugValido, slugify } from '../dominio/slugs'

type Opciones = {
  desde: string
  localizado: boolean
  validarExtra?: (slug: string) => string | true
}

export function campoSlug({ desde, localizado, validarExtra }: Opciones): TextField {
  const generar: FieldHook = ({ value, siblingData }) => {
    if (typeof value === 'string' && value.trim() !== '') return slugify(value)
    const origen = siblingData?.[desde]
    return typeof origen === 'string' && origen.trim() !== '' ? slugify(origen) : value
  }

  return {
    name: 'slug',
    type: 'text',
    localized: localizado,
    unique: true,
    index: true,
    admin: { position: 'sidebar', description: 'Se genera del nombre; minúsculas sin acentos, con guiones.' },
    hooks: { beforeValidate: [generar] },
    validate: (valor: unknown) => {
      if (valor === null || valor === undefined || valor === '') return true
      if (typeof valor !== 'string' || !esSlugValido(valor)) return 'Slug inválido: minúsculas, números y guiones.'
      return validarExtra ? validarExtra(valor) : true
    },
  } as TextField
}

import { s3Storage } from '@payloadcms/storage-s3'
import type { Plugin } from 'payload'

export type EntornoR2 = Partial<
  Record<'R2_ACCOUNT_ID' | 'R2_ACCESS_KEY_ID' | 'R2_SECRET_ACCESS_KEY' | 'R2_BUCKET' | 'R2_PUBLIC_URL', string>
>

type OpcionesS3 = Parameters<typeof s3Storage>[0]

// Siempre el mismo plugin (activado o no) para que esquema, migraciones e importMap sean iguales
// en local, CI y producción (spec §4.2; ver revisión de arquitectura del plan).
export function opcionesAlmacenamiento(env: EntornoR2): OpcionesS3 {
  const activo = Boolean(env.R2_BUCKET)
  const urlPublica = (env.R2_PUBLIC_URL ?? '').replace(/\/+$/, '')
  if (activo && !urlPublica) throw new Error('Falta R2_PUBLIC_URL: las imágenes se sirven desde el dominio del bucket.')

  return {
    enabled: activo,
    alwaysInsertFields: true,
    clientUploads: true,
    bucket: env.R2_BUCKET || 'sin-bucket',
    collections: {
      media: {
        disablePayloadAccessControl: true,
        generateFileURL: ({ filename, prefix }) => `${urlPublica}/${prefix ? `${prefix}/` : ''}${filename}`,
      },
    },
    config: {
      endpoint: env.R2_ACCOUNT_ID ? `https://${env.R2_ACCOUNT_ID}.r2.cloudflarestorage.com` : undefined,
      region: 'auto',
      credentials: {
        accessKeyId: env.R2_ACCESS_KEY_ID ?? '',
        secretAccessKey: env.R2_SECRET_ACCESS_KEY ?? '',
      },
    },
  }
}

export function pluginsAlmacenamiento(env: EntornoR2): Plugin[] {
  return [s3Storage(opcionesAlmacenamiento(env))]
}

import { LOCALES, type Locale } from '../dominio/idioma'

// Estado publicado de un documento (tabla principal), por idioma.
export type Instantanea = {
  publicado: boolean
  slugs: Partial<Record<Locale, string>>
  existe: Record<Locale, boolean>
}

export type Cambio =
  | { tipo: 'cambioSlug'; locale: Locale; slugViejo: string; slugNuevo: string }
  | { tipo: 'retiro'; locale: Locale; slug: string }

export const NO_PUBLICADO: Instantanea = { publicado: false, slugs: {}, existe: { es: false, en: false } }

export function calcularCambios(antes: Instantanea, despues: Instantanea): Cambio[] {
  if (!antes.publicado) return []
  const cambios: Cambio[] = []
  for (const locale of LOCALES) {
    const viejo = antes.slugs[locale]
    if (!antes.existe[locale] || !viejo) continue
    const nuevo = despues.slugs[locale]
    const sigueVivo = despues.publicado && despues.existe[locale] && Boolean(nuevo)
    if (!sigueVivo) cambios.push({ tipo: 'retiro', locale, slug: viejo })
    else if (nuevo !== viejo) cambios.push({ tipo: 'cambioSlug', locale, slugViejo: viejo, slugNuevo: nuevo! })
  }
  return cambios
}

import type { PayloadRequest } from 'payload'

// Único punto que escribe en `redirects`. Usa la Local API con `req` (misma transacción) y SIN `locale`:
// la colección no es localizada y así no se toca req.locale (regla de hooks del plan).
export async function registrarRedireccion(
  req: PayloadRequest,
  { desde, hacia }: { desde: string; hacia: string },
): Promise<void> {
  if (desde === hacia) return
  const { payload } = req
  const comun = { overrideAccess: true, req, depth: 0, context: { ...req.context, sinRedirecciones: true } } as const

  // La ruta destino vuelve a estar viva: no puede salir una redirección de ella.
  await payload.delete({ collection: 'redirects', where: { from: { equals: hacia } }, ...comun })
  // Sin cadenas: lo que apuntaba a `desde` ahora apunta a `hacia`.
  await payload.update({
    collection: 'redirects',
    where: { 'to.url': { equals: desde } },
    data: { to: { type: 'custom', url: hacia } },
    ...comun,
  })
  const existente = await payload.find({ collection: 'redirects', where: { from: { equals: desde } }, limit: 1, ...comun })
  const data = { from: desde, to: { type: 'custom' as const, url: hacia }, type: '308' as const }
  if (existente.docs[0]) {
    await payload.update({ collection: 'redirects', id: existente.docs[0].id, data, ...comun })
  } else {
    await payload.create({ collection: 'redirects', data, ...comun })
  }
}

import type {
  CollectionAfterChangeHook,
  CollectionAfterDeleteHook,
  CollectionBeforeChangeHook,
  CollectionBeforeDeleteHook,
  CollectionSlug,
  PayloadRequest,
} from 'payload'

import { aplanarIdioma, existeEnIdioma, LOCALES, type Locale } from '../dominio/idioma'
import { rutas } from '../dominio/rutas'
import { combinacionTienePagina } from '../dominio/umbrales'
import { calcularCambios, NO_PUBLICADO, type Instantanea } from './diferencias'
import { registrarRedireccion } from './registrar'

type Doc = Record<string, unknown> & { id: number | string }

export type OpcionesRedireccion = {
  coleccion: CollectionSlug
  camposIdioma: readonly string[]
  camposLocalizados: readonly string[]
  rutaDe: (locale: Locale, slug: string) => string
  destinoAlRetirar: (req: PayloadRequest, antes: Doc, locale: Locale) => Promise<string>
}

const LLAVE = 'redirecciones:instantaneas'
const omitir = (req: PayloadRequest) => Boolean(req.context?.sinRedirecciones)

// Un Map por req: las operaciones masivas del admin procesan varios documentos en paralelo con el mismo req.
function almacen(req: PayloadRequest): Map<string, Doc | null> {
  let m = req.context[LLAVE] as Map<string, Doc | null> | undefined
  if (!m) {
    m = new Map()
    req.context[LLAVE] = m
  }
  return m
}

// Lee la tabla principal (lo publicado) con el adaptador: no pasa por createLocalReq, no toca req.locale,
// usa la transacción de req y devuelve null si no existe.
async function leerTablaPrincipal(
  req: PayloadRequest,
  coleccion: CollectionSlug,
  id: number | string,
  locale: string = 'all',
): Promise<Doc | null> {
  return (await req.payload.db.findOne({ collection: coleccion, where: { id: { equals: id } }, locale, req })) as Doc | null
}

export function instantaneaDe(doc: Doc | null, op: Pick<OpcionesRedireccion, 'camposIdioma' | 'camposLocalizados'>): Instantanea {
  if (!doc) return NO_PUBLICADO
  const slugs: Instantanea['slugs'] = {}
  const existe = { es: false, en: false } as Instantanea['existe']
  for (const l of LOCALES) {
    const plano = aplanarIdioma(doc, l, op.camposLocalizados)
    slugs[l] = typeof plano.slug === 'string' && plano.slug ? plano.slug : undefined
    existe[l] = existeEnIdioma(plano, op.camposIdioma)
  }
  return { publicado: doc._status === 'published', slugs, existe }
}

async function aplicar(req: PayloadRequest, op: OpcionesRedireccion, antes: Doc | null, despues: Doc | null) {
  if (!antes) return
  for (const c of calcularCambios(instantaneaDe(antes, op), instantaneaDe(despues, op))) {
    const desde = op.rutaDe(c.locale, c.tipo === 'cambioSlug' ? c.slugViejo : c.slug)
    const hacia = c.tipo === 'cambioSlug' ? op.rutaDe(c.locale, c.slugNuevo) : await op.destinoAlRetirar(req, antes, c.locale)
    await registrarRedireccion(req, { desde, hacia })
  }
}

export function hooksDeRedireccion(op: OpcionesRedireccion) {
  const llave = (id: number | string) => `${op.coleccion}:${id}`

  const beforeChange: CollectionBeforeChangeHook = async ({ data, operation, originalDoc, req }) => {
    if (omitir(req) || operation !== 'update' || !originalDoc?.id) return data
    almacen(req).set(llave(originalDoc.id), await leerTablaPrincipal(req, op.coleccion, originalDoc.id))
    return data
  }

  const afterChange: CollectionAfterChangeHook = async ({ doc, operation, req }) => {
    if (omitir(req) || operation !== 'update') return doc
    const m = almacen(req)
    const k = llave(doc.id)
    if (!m.has(k)) return doc
    const antes = m.get(k) ?? null
    m.delete(k)
    await aplicar(req, op, antes, await leerTablaPrincipal(req, op.coleccion, doc.id))
    return doc
  }

  const beforeDelete: CollectionBeforeDeleteHook = async ({ id, req }) => {
    if (omitir(req)) return
    almacen(req).set(llave(id), await leerTablaPrincipal(req, op.coleccion, id))
  }

  const afterDelete: CollectionAfterDeleteHook = async ({ id, req, doc }) => {
    if (omitir(req)) return doc
    const m = almacen(req)
    const k = llave(id)
    const antes = m.get(k) ?? null
    m.delete(k)
    await aplicar(req, op, antes, null)
    return doc
  }

  return { beforeChange, afterChange, beforeDelete, afterDelete }
}

// --- Destinos al retirar (spec §6, Redirecciones) ---

const idDe = (v: unknown): number | string | undefined =>
  v && typeof v === 'object' ? (v as { id?: number | string }).id : (v as number | string | undefined)

async function zonaActiva(req: PayloadRequest, zona: unknown): Promise<{ id: number | string; slug: string } | null> {
  const id = idDe(zona)
  if (!id) return null
  const z = (await req.payload.db.findOne({ collection: 'zonas', where: { id: { equals: id } }, req })) as
    | { id: number | string; slug?: string; activa?: boolean }
    | null
  return z?.activa && z.slug ? { id: z.id, slug: z.slug } : null
}

export async function destinoAlRetirarLugar(req: PayloadRequest, antes: Doc, locale: Locale): Promise<string> {
  const zona = await zonaActiva(req, antes.zona)
  if (!zona) return rutas.portada(locale)
  const catId = idDe(Array.isArray(antes.categorias) ? antes.categorias[0] : undefined)
  if (catId) {
    const cat = (await req.payload.db.findOne({ collection: 'categorias', where: { id: { equals: catId } }, locale, req })) as
      | { slug?: string }
      | null
    const { totalDocs } = await req.payload.db.count({
      collection: 'lugares',
      locale,
      req,
      where: {
        and: [
          { zona: { equals: zona.id } },
          { categorias: { in: [catId] } },
          { _status: { equals: 'published' } },
          { slug: { exists: true } },
          { resumen: { exists: true } },
          { cuerpo: { exists: true } },
        ],
      },
    })
    if (cat?.slug && combinacionTienePagina(totalDocs)) return rutas.categoriaEnZona(locale, zona.slug, cat.slug)
  }
  return rutas.zona(locale, zona.slug)
}

export async function destinoAlRetirarArticulo(req: PayloadRequest, antes: Doc, locale: Locale): Promise<string> {
  const zona = await zonaActiva(req, Array.isArray(antes.zonas) ? antes.zonas[0] : undefined)
  return zona ? rutas.zona(locale, zona.slug) : rutas.portada(locale)
}

export async function destinoAlRetirarEvento(_req: PayloadRequest, _antes: Doc, locale: Locale): Promise<string> {
  return rutas.eventos(locale)
}

// --- Zonas (slug sin localizar, sin borradores) ---

export function hooksDeZona() {
  const afterChange: CollectionAfterChangeHook = async ({ doc, previousDoc, operation, req }) => {
    if (omitir(req) || operation !== 'update') return doc
    const viejo = previousDoc?.slug as string | undefined
    const nuevo = doc.slug as string | undefined
    if (!previousDoc?.activa || !viejo || !nuevo || viejo === nuevo) return doc
    const categorias = (await req.payload.db.find({ collection: 'categorias', locale: 'all', pagination: false, req }))
      .docs as Doc[]
    for (const l of LOCALES) {
      await registrarRedireccion(req, { desde: rutas.zona(l, viejo), hacia: rutas.zona(l, nuevo) })
      for (const c of categorias) {
        const slugCat = aplanarIdioma(c, l, ['slug']).slug
        if (typeof slugCat !== 'string' || !slugCat) continue
        await registrarRedireccion(req, {
          desde: rutas.categoriaEnZona(l, viejo, slugCat),
          hacia: rutas.categoriaEnZona(l, nuevo, slugCat),
        })
      }
    }
    return doc
  }
  return { afterChange }
}

// --- Categorías (slug localizado, sin borradores) ---

export function hooksDeCategoria() {
  const llave = (id: number | string) => `categorias:${id}`

  const beforeChange: CollectionBeforeChangeHook = async ({ data, operation, originalDoc, req }) => {
    if (omitir(req) || operation !== 'update' || !originalDoc?.id) return data
    almacen(req).set(llave(originalDoc.id), await leerTablaPrincipal(req, 'categorias', originalDoc.id))
    return data
  }

  const afterChange: CollectionAfterChangeHook = async ({ doc, operation, req }) => {
    if (omitir(req) || operation !== 'update') return doc
    const m = almacen(req)
    const k = llave(doc.id)
    if (!m.has(k)) return doc
    const antes = m.get(k)
    m.delete(k)
    const despues = await leerTablaPrincipal(req, 'categorias', doc.id)
    if (!antes || !despues) return doc
    const zonas = (await req.payload.db.find({ collection: 'zonas', pagination: false, req })).docs as Doc[]
    for (const l of LOCALES) {
      const viejo = aplanarIdioma(antes, l, ['slug']).slug
      const nuevo = aplanarIdioma(despues, l, ['slug']).slug
      if (typeof viejo !== 'string' || typeof nuevo !== 'string' || !viejo || !nuevo || viejo === nuevo) continue
      await registrarRedireccion(req, { desde: rutas.categoria(l, viejo), hacia: rutas.categoria(l, nuevo) })
      for (const z of zonas) {
        if (typeof z.slug !== 'string') continue
        await registrarRedireccion(req, {
          desde: rutas.categoriaEnZona(l, z.slug, viejo),
          hacia: rutas.categoriaEnZona(l, z.slug, nuevo),
        })
      }
    }
    return doc
  }

  return { beforeChange, afterChange }
}

  const dia = 24 * 60 * 60 * 1000
  await vaciarColecciones(payload)

  const admin = await payload.create({
    collection: 'users',
    data: {
      email: 'admin@guia.local',
      password: opciones.contrasenaAdmin ?? 'cambia-esta-contrasena',
      nombrePublico: 'Equipo de la guía',
      rol: 'admin',
    },
    overrideAccess: true,
    context: ctx,
  })

  const fotos = []
  for (const [i, color] of [{ r: 20, g: 110, b: 150 }, { r: 210, g: 160, b: 90 }, { r: 60, g: 140, b: 90 }].entries()) {

        file: { data, mimetype: 'image/jpeg', name: `semilla-${i + 1}.jpg`, size: data.length },
        overrideAccess: true,
        context: ctx,
      }),
    )
  }
  for (const f of fotos) {
    await payload.update({ collection: 'media', id: f.id, locale: 'en', data: { alt: `Sample photo ${f.id}` }, overrideAccess: true, context: ctx })
  }

  const zonas = []
  for (const z of [

  }

  for (const [i, c] of CATEGORIAS.entries()) {
    const doc = await payload.create({
      collection: 'categorias', locale: 'es',
      data: { nombre: c.es, aplicaA: c.aplica, tipoSchema: c.tipo, orden: i + 1 },
      overrideAccess: true, context: ctx,
    })
    await payload.update({ collection: 'categorias', id: doc.id, locale: 'en', data: { nombre: c.en }, overrideAccess: true, context: ctx })
    categorias.push(doc)
  }

  const lugares = []
  for (const [i, l] of LUGARES.entries()) {
    const doc = await payload.create({

          : { activo: false },
        _status: 'published',
      },
      overrideAccess: true, context: ctx,
    })
    if (l.en) {
      await payload.update({
        collection: 'lugares', id: doc.id, locale: 'en',
        data: { resumen: `${l.nombre}: made-up place for testing in La Paz.`, cuerpo: parrafo(`Sample text about ${l.nombre}.`), _status: 'published' },
        overrideAccess: true, context: ctx,
      })
    }
    lugares.push(doc)
  }

  for (const e of [
    { nombre: 'Feria de prueba (pasada)', dias: -10 },
    { nombre: 'Concierto de prueba', dias: 7 },
    { nombre: 'Festival inventado', dias: 20 },
  ]) {
    const inicio = new Date(ahora.getTime() + e.dias * dia).toISOString()
    const doc = await payload.create({
      collection: 'eventos', locale: 'es',
      data: {
        nombre: e.nombre, zona: zonas[0].id, categorias: [categorias[6].id], lugar: lugares[0].id, inicio,

        gratis: true, _status: 'published',
      },
      overrideAccess: true, context: ctx,
    })
    await payload.update({
      collection: 'eventos', id: doc.id, locale: 'en',
      data: { nombre: `${e.nombre} (EN)`, resumen: `${e.nombre} in La Paz.`, cuerpo: parrafo(`Details of ${e.nombre}.`), _status: 'published' },
      overrideAccess: true, context: ctx,

      },
    )
    return c
  }
  for (const a of [
    { es: 'Qué hacer en La Paz (prueba)', en: 'What to do in La Paz (sample)' },
    { es: 'Dónde comer en La Paz (prueba)', en: 'Where to eat in La Paz (sample)' },
  ]) {
    const doc = await payload.create({
      collection: 'articulos', locale: 'es',
      data: {
        titulo: a.es, zonas: [zonas[0].id], portada: fotos[2].id, autor: admin.id,
        resumen: `${a.es}.`, cuerpo: cuerpoArticulo(`Respuesta directa: ${a.es}.`), _status: 'published',
      },
      overrideAccess: true, context: ctx,
    })
    await payload.update({
      collection: 'articulos', id: doc.id, locale: 'en',
      data: { titulo: a.en, resumen: `${a.en}.`, cuerpo: cuerpoArticulo(`Direct answer: ${a.en}.`), _status: 'published' },
      overrideAccess: true, context: ctx,
    })
  }

  await payload.updateGlobal({
    slug: 'ajustes-guia',
    locale: 'es',
    data: {
      correosAviso: [{ correo: 'avisos@guia.local' }],
      correoPrivacidad: 'privacidad@guia.local',
      formularioActivo: false,
      portadaTitulo: 'Guía de la Baja (datos de prueba)',
      portadaIntro: 'Contenido inventado para desarrollo.',
    },
    overrideAccess: true,
    context: ctx,
  })

  return { admin: 'admin@guia.local' }
}

1. Push del repo a GitHub, ruleset y environment `respaldos` (docs/operacion.md).
2. Conectar Vercel, variables por entorno, primer deploy a producción con `GUIA_INDEXABLE=false`.
3. Desde ese deploy: **prohibido** `npm run migracion:regenerar`; toda migración nueva con `migrate:create`.
4. Verificaciones de F2 en `docs/operacion.md`.
